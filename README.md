# 中文互联网理论演变观察（xx-theories）

收录中文互联网上以“XX理论 / XX思维”命名的流行说法，记录它们的出处、时间线、核心观点、争议和事实核查，并观察不同代际理论之间的演变。

> 本仓库为社会现象记录，不代表认同任何理论观点；健康类内容不构成医疗建议。
